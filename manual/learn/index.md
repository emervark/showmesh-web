# Learning

A **cue defines a lifecycle**, an **action adds behaviour**, and a **trigger
decides when it fires**.

1. [Cues and the cue list](/learn/cues) — arming, states, timing, timecode GO, and transport.
2. [Actions and triggers](/learn/actions-and-triggers) — commands, values, fades, and external triggers.
3. [Transitions](/learn/transitions) — parameter motion and crossfades.
4. [Layers and compositing](/learn/layers) — order, opacity, and geometry.

For allowed fields and values, use [Reference](/reference/).
